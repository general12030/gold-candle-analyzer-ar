# Gold Candle Analyzer AR

تطبيق Android عربي لتحليل `XAUUSDc` على فريم 5 دقائق، مع إشارات تعليمية للشراء والبيع وسجل محلي.

## الحالة
نسخة أولية قابلة للبناء. مصدر الأسعار الافتراضي هو خدمة تجريبية قابلة للاستبدال. اترك خانة `BROKER_API_BASE_URL` فارغة حتى يتم توفير خادم One Royal لاحقًا.

## البناء
افتح المشروع في Android Studio (Ladybug أو أحدث)، ثم شغّل:

```bash
./gradlew assembleDebug
```

سيكون الناتج في `app/build/outputs/apk/debug/app-debug.apk`.

## مصدر البيانات
- `DemoMarketDataSource`: بيانات تجريبية واضحة للاختبار فقط.
- `BrokerMarketDataSource`: نقطة ربط مستقبلية لخادم One Royal، ولا يحتوي التطبيق على بيانات حساب أو كلمة مرور.

لا تعتبر الإشارات توصية مالية أو ضمانًا للربح. يجب اختبار مصدر البيانات والاستراتيجية على حساب تجريبي قبل أي استخدام حقيقي.
